# Transcripts

This folder contains official academic transcripts for each semester of the B.Sc. Engineering (Hons) degree at University of Moratuwa.

## Structure

Place transcript files here using the naming convention:

```
Transcript_SemesterX_YYYY.pdf
```

For example:
- `Transcript_Semester1_2021.pdf`
- `Transcript_Semester2_2021.pdf`
- `Transcript_Semester3_2022.pdf`
