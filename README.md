## Repository Structure

```
Academic-Records/
├── transcripts/   # Official academic transcripts (per semester)

```

## Naming Convention

| Folder | File pattern | Example |
|--------|-------------|---------|
| `transcripts/` | `Transcript_SemesterX_YYYY.pdf` | `Transcript_Semester1_2021.pdf` |
| `results/` | `Results_SemesterX_YYYY.pdf` | `Results_Semester1_2021.pdf` |
