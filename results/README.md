# Results

This folder contains exam results and grade sheets for each semester of the B.Sc. Engineering (Hons) degree at University of Moratuwa.

## Structure

Place result files here using the naming convention:

```
Results_SemesterX_YYYY.pdf
```

For example:
- `Results_Semester1_2021.pdf`
- `Results_Semester2_2021.pdf`
- `Results_Semester3_2022.pdf`
